# Agent Note: 翻译只翻不答，备选有序，栏上显示连接名

Status: implemented

## Problem

翻译模型被问到问题时会顺带回答，违背「只翻不答」；翻译结果栏曾显示 provider id（openai-compatible）而非连接名，三个连接共享同一个 provider id，分不清是哪一个，也无法定位。

## Decision

每机器人一个翻译模型，只翻不答；图、视频、翻译均支持有序备选，失败换下一个、全部失败才报错并列出原因；服务端翻译成功时始终回传 attempts（含连接名），客户端栏上显示连接名并据此定位；旧译文（无 attempts）重翻一次才带连接名。

## Alternatives considered

- **翻译兼回答** — 少一次调用；但用户明确只要翻译，回答是越权。
- **栏上显示 provider id** — 实现最简单；但三个连接共享同一个 provider id，分不清是哪一个，定位也只能落到第一个同 provider 的连接。
- **失败即报错，不换备选** — 逻辑简单；但一次抖动就断掉翻译，用户要求自动换下一个。

## Consequences

- **收益**：翻译行为可预测，栏可定位；备选链让单次失败不再打断翻译。
- **代价与已知上限**：服务端每次翻译都多带 attempts；旧译文重翻一次才带连接名；模型后端本身不稳时（503、401）备选链也救不了。
